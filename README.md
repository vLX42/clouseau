# Todo List App

## Overview
This is a simple Todo List application built with React and Vite. Users can add, toggle, and remove todos efficiently.

## Features
- Add todos using a text input and an 'Add' button.
- Mark todos as done with a checkbox toggle.
- Remove todos from the list.
- Local storage integration to persist todos.

## Accessibility
- All inputs are labeled appropriately for screen readers.
- Focus is maintained on the input field after actions.
- Clear instructions and prompts enhance usability for all users.
